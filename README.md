# 幕墙分格与反射检查系统

浏览器内的自由曲面幕墙深化设计工具：曲面控制网格编辑、自动分格、玻璃板翘曲量计算与平板/冷弯/热弯分类、接缝检查、环境反射与斑马纹预览。TypeScript + WebGPU 计算 + WebGL2 渲染，纯前端、数据存浏览器本地。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm test           # 翘曲量数学核心测试（25 个用例）
npm run build      # 类型检查 + 生产构建
```

## 翘曲量算法（核心）

每块四边形玻璃板计算三套**互相独立**的指标，单位 mm：

1. **拟合平面偏差 `planeDev`（主分类指标）**——四角点协方差矩阵经 12 轮 Jacobi 特征分解，最小特征值方向即最佳拟合平面法向，取角点到该平面有向距离的最大绝对值。
2. **对角线中点距离 `diagMid`**——`|(P0+P2)/2 − (P1+P3)/2|`，纯封闭解析解，无迭代。
3. **三角平面距离 `triGap`**——四点各自到其余三点所成三角形平面（叉积法向）的距离最大值。

### 精度保证

- WGSL 计算着色器（`src/gpu/panel.wgsl.ts`）与 CPU 参考实现（`src/engine/warp.ts`、`jacobi.ts`）逐行同构。
- 测试用 **Fibonacci 球面粗搜 + 切平面局部细化**的独立暴力搜索法核对 PCA 结果，另含手算鞍形板封闭解。
- 设置页"GPU/CPU 一致性校验"对同一组板块分别走两条路径，实测三指标最大绝对误差约 **2×10⁻⁴ mm**，远严于 0.1mm 验收线。
- 分类阈值默认：≤3mm 平板，≤25mm 冷弯，否则热弯（可在设置页调整）。

## 性能

- 计算：WebGPU compute pipeline（workgroup 64），持久化 buffer 不重建、读回缓冲串行化；不支持时自动降级 Web Worker，再降级主线程。
- 实测 10000 块板完整分析（分格+翘曲+接缝+统计）约 **36ms**，拖控制点经 rAF 合并后保持 60fps。
- 渲染：WebGL2 无依赖手写管线，面板按三角形批量提交。

## 接缝模型

相邻面板共享理论分格线，按名义半缝宽 h 在接缝法向上错开 ±h：共面时缝宽恰为 2h、高差与折角为 0。输出缝宽偏差、法向高差（错台）、面法向夹角（折角），任一超阈值即标红并在报表中列出原因。
