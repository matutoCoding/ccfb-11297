# 幕墙分格与反射检查系统

浏览器端自由曲面幕墙深化设计工具：把建筑师的自由曲面拆分为可加工的玻璃板块，自动判定平板 / 冷弯 / 热弯，检查接缝与反射连续性。**TypeScript + WebGPU + WebGL2，纯前端、零三维引擎依赖，数据存本地可导出。**

## 功能

| 模块 | 能力 |
| --- | --- |
| 项目列表 | 增删改复制，IndexedDB 本地持久化，JSON 导入导出 |
| 曲面编辑 | 控制网格（双线性 / Catmull-Rom）定义自由曲面，拖拽控制点改形，5 种预设 |
| 分格 | 经纬线（UV）或等弧长（等距）分格，板块尺寸上下限、设计缝宽可设 |
| 面板检查 | 逐板翘曲量，按平板/冷弯/热弯分类上色，接缝宽度与错台超限标红，CSV 清单导出 |
| 反射预览 | 斑马纹环境检查反射连续性，相邻板法向夹角量化 |
| 设置 | 三种翘曲公式切换、判定阈值、GPU/CPU 一键对拍 |
| 截图 | 画布 + 统计数字合成 PNG |

## 翘曲量的准确性（核心）

系统对每块四边形玻璃板同时计算**三种相互独立**的翘曲量，单位毫米：

1. **三点定面法 `three-point`**（JGJ 102 行业惯例）：依次以四个三角面为参考平面，取第四点到平面距离的最大值。
2. **最佳拟合平面法 `best-fit`**：四点形心协方差矩阵的最小特征向量定面，输出平面度峰峰值（PV）。
3. **对角线异面距离法 `diagonal`**：两条对角线之间的异面最短距离，与冷弯贴合应力相关性好。

另有第四路径 `crossCheckDistance`（纯混合积代数形式）在测试中与主实现交叉核对。

### 双精度基准 + 双路独立实现

- **CPU 侧全部 Float64**（`src/core/`），是唯一权威结果，无 DOM/GPU 依赖，可在 Node 直接运行。
- **GPU 侧 WGSL Float32**（`src/gpu/`）是独立的第二套代码，compute shader 并行，用于拖拽实时反馈。
- 着色器内对每块板按**质心重定位**到局部坐标（量级 ~1.5m），抵消大绝对坐标下 f32 的灾难性抵消。
- 应用内「设置 → GPU/CPU 对拍」逐板比较，验收门槛 **最大绝对差 < 0.1mm**。

### 验证证据

| 测试 | 内容 | 结果 |
| --- | --- | --- |
| 已知答案夹具 | 平面=0、单角抬高（解析值）、扭转、共线退化、50m 大坐标 | 误差 ~1e-6mm |
| 2000 组随机四边形模糊测试 | 独立公式互校 | 最大差 < 1e-9mm |
| WGSL f32 算法等价复刻（万板） | `Math.fround` 单精度逐行复刻着色器 | 最大差 **2.0e-4mm** |
| 真实 Dawn WebGPU compute（`npm run test:gpu`） | 实跑 WGSL 读回对拍 | 最大差 **1.8e-4mm** |

均远优于 0.1mm 工程门槛。

## 性能（上万块板拖拽不卡）

- f64 引擎单次重算 10000 块板约 **70–100ms**（见 `engine.test.ts` 基准）。
- 拖拽控制点走内存态实时重算（不写库），`requestAnimationFrame` 渲染，松手后才持久化。
- WebGPU compute 路径 `workgroup_size(64)` 并行，不支持 WebGPU 时自动回退 CPU，功能不缺失。

## 技术架构

```
src/
  core/        纯 f64 数学引擎 (零依赖, 可 Node 运行, 含全部单元测试)
    vec3.ts        向量运算
    surface.ts     曲面求值、弧长参数化
    presets.ts     预设曲面
    warp.ts        三种翘曲公式 + 混合积交叉核对
    engine.ts      分格、内缩缝、接缝检查、统计
    csv.ts         清单导出
  gpu/         WebGPU compute (WGSL f32, 独立实现)
  render/      WebGL2 渲染器 + 轨道相机 (自研, 无三维引擎)
  state/       IndexedDB 持久化 + 信号 store
  ui/          Preact 页面与组件
```

## 命令

```bash
npm install
npm run dev        # 开发服务器
npm test           # 25 个单元/集成/模糊/基准测试 (f64 + f32 复刻)
npm run test:gpu   # 真实 Dawn WebGPU compute 端到端 (需 npm i -D webgpu)
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

## 浏览器要求

- WebGPU：Chrome/Edge 113+ 获得完整 compute 加速；不支持时自动降级 CPU f64。
- WebGL2：所有现代浏览器均支持，用于三维显示。
